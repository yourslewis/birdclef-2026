# ClawTeam Phases

## Mode
- Coordinator-led.
- Safe parallel for independent analysis.
- Verifier gate before any Kaggle submission.
- Report after each major phase.

## Phase 1 — Plateau and Ensemble Diagnosis
Parallel agents:
1. Solution Lineage Analyst
2. Prediction & Ensemble Analyst
3. Data & Feature Scientist
4. Validation & Metrics Scientist

Coordinator output: accepted/revise/block decisions and implementation plan.

## Phase 2 — Implement Ensemble Candidate
Only after Phase 1 synthesis. Build a repo-owned no-slot verifier/kernel or local/trainer ensemble audit.

## Phase 3 — Verify / Submit Decision
Independent verifier reviews schema/runtime/leakage/hidden-test safety and validation evidence. Submission requires explicit Coordinator approval.
